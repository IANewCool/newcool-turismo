# NewCool Turismo - SERNATUR Chile

Portal educativo sobre turismo y SERNATUR en Chile.

## Demo

[https://turismo.newcool.io](https://turismo.newcool.io)

## Caracteristicas

- Buscador de oficinas SERNATUR
- Guia de destinos turisticos
- Calculadora de presupuesto de viaje
- Derechos del turista
- Rutas y circuitos

## Tecnologias

- Next.js 15
- React 19
- Tailwind CSS 4
- TypeScript

## Desarrollo

```bash
npm install
npm run dev
```

## Parte del Ecosistema NewCool

Este modulo es parte de [NewCooltura Informada](https://informada.newcool.io) - Portal de instituciones publicas de Chile.
